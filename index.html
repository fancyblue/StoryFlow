Google Picker API Key

API Key 會保存在你選擇的 StoryFlow 資料夾 settings.json，不寫入 GitHub 或瀏覽器儲存空間。

StoryFlow 資料夾

同一個瀏覽器工作階段內，重新整理頁面會自動接回目前資料夾，不需要重新選擇。關閉瀏覽器／頁籤後再次開啟時，可以要求你重新選擇或重新授權資料夾。

發布排版

初始提供「巴哈小屋、方格子」，兩者都可以移除，也可以自行新增其他平台；每個平台可個別設定排版。

保存位置：工作進度 → workspace.json；Google 整合、平台與排版設定 → settings.json；文章 → Works/。為了讓單純重新整理不必重新登入，Google access token 只會暫存在目前瀏覽器工作階段的 sessionStorage，不會寫入 localStorage；「離開此裝置」會清除 token、暫存設定與已記住的 StoryFlow 資料夾連線，但不會刪除資料夾內檔案。
