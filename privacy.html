StoryFlow 隱私權政策

最後更新：2026 年 10 月 16 日

StoryFlow 是在你的瀏覽器中執行的個人寫作工作台，用來把長篇原稿切成適合發布的篇幅，並整理各平台的發布稿。網站只是一組由 GitHub Pages 提供的靜態檔案：StoryFlow 沒有自己的伺服器、帳號系統、分析工具或廣告追蹤，也不使用 Cookie 追蹤你。

StoryFlow 會存取哪些 Google 資料

連接 Google 時，StoryFlow 只申請一項權限：https://www.googleapis.com/auth/drive.file。這項權限只能存取你透過 Google 檔案選擇器（Google Picker）主動選取的檔案，看不到你雲端硬碟裡的其他檔案。

  • StoryFlow 用它讀取你選的 Google 文件內容，轉成可以切篇的文字。
  • StoryFlow 不會修改或刪除你的 Google 文件；Google 文件永遠只是來源。
  • 讀取到的內容只在你的瀏覽器裡處理，接著寫進你選擇的 StoryFlow 資料夾（見下一節），不會傳送到 StoryFlow 或任何第三方的伺服器。

你的作品保存在哪裡

原稿內容、切篇進度、產出的文章與圖片，以及你的設定（包括你自己填入的 Google OAuth Client ID 與 Picker API Key），都寫進你在電腦上選擇的 StoryFlow 資料夾。這是透過瀏覽器的檔案系統存取功能完成的，資料只存在你的裝置上，或你自己選擇同步這個資料夾的雲端服務中。

StoryFlow 的程式碼公開在 GitHub，但 GitHub 上只有程式，不會有你的原稿、圖片或設定。

瀏覽器裡暫存的資料

為了讓你重新整理頁面時不必每次重來，StoryFlow 會在你的瀏覽器中保存少量資料：

  • 這次工作階段（關閉分頁或瀏覽器後消失）：Google 存取權杖與到期時間、從 settings.json 匯入的整合設定、資料夾與手機編輯模式的連線狀態。
  • 這個瀏覽器（保留到你清除網站資料）：介面偏好，例如側欄是否收合、左欄寬度、閱讀設定的字級與行高；以及你上次選擇的資料夾位置（只記得是哪個資料夾，不包含其中的內容）。

到「設定 → 裝置與隱私」按「離開此裝置」，可以清除這個瀏覽器中的 Google 登入、暫存設定與資料夾連線；StoryFlow 資料夾裡的作品不會被刪除。介面偏好可以透過瀏覽器的「清除網站資料」移除。

第三方服務

  • Google：登入使用 Google Identity Services，選檔使用 Google Picker，讀取文件使用 Google Docs API。這些請求由你的瀏覽器直接連到 Google，適用 Google 隱私權政策。
  • GitHub Pages：提供網站的靜態檔案。GitHub 可能依其 隱私權聲明 記錄一般的連線紀錄（例如 IP 位址）；StoryFlow 本身不讀取這些紀錄。

資料的使用與分享

StoryFlow 不出售、不出租、不分享你的資料，也不將其用於廣告、分析或訓練人工智慧模型。

StoryFlow 對透過 Google API 取得之資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）規定。

撤銷存取權與刪除資料

  • 隨時可到 Google 帳戶的 第三方應用程式存取權 移除 StoryFlow 的授權。
  • 在 StoryFlow 的「設定 → 裝置與隱私」按「離開此裝置」，清除這個瀏覽器中的登入與暫存資料。
  • 你的作品都在你自己的 StoryFlow 資料夾裡，刪除那個資料夾就會刪除所有作品資料。

政策變更

如果 StoryFlow 處理資料的方式改變，會更新這一頁並修改上方的「最後更新」日期。每次修改都記錄在 GitHub 的版本歷史中。

聯絡方式

有任何隱私相關的問題，請到 GitHub 開一則 Issue：github.com/fancyblue/StoryFlow/issues。Issue 是公開的，請不要在裡面貼原稿內容、存取權杖、Client ID 或 API Key。

Privacy Policy (English summary)

Last updated: October 16, 2026

StoryFlow is a personal writing workbench that runs entirely in your browser. It is served as static files from GitHub Pages and has no server, accounts, analytics or advertising trackers of its own.

Google data

StoryFlow requests a single OAuth scope, https://www.googleapis.com/auth/drive.file, which only grants access to files you explicitly pick in the Google Picker. It reads the content of the Google Docs you select so it can split them into publishable parts. It never modifies or deletes your Google Docs, and the content is processed in your browser and written only to a folder on your device that you choose. It is never sent to StoryFlow or any third-party server.

Where your data is stored

Manuscripts, progress, generated articles, images and settings (including the Google OAuth Client ID and Picker API Key you provide) are stored in the StoryFlow folder you select, through the browser's File System Access API. The browser itself keeps only session data (the Google access token and its expiry, imported integration settings, connection state), interface preferences, and a handle to the folder you chose. “Leave this device” in Settings clears the sign-in, cached settings and folder connection.

Sharing and use

StoryFlow does not sell, rent or share your data, and does not use it for advertising, analytics or training AI models. StoryFlow's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can remove StoryFlow's access at any time from your Google Account's third-party access page. Deleting your StoryFlow folder deletes all of your work data.

Contact

Open an issue at github.com/fancyblue/StoryFlow/issues. Issues are public, so please do not include manuscript text, tokens or credentials.
